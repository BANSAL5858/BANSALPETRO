# BANSALPETRO

Minimal MVP code for a petrol pump management system. The current prototype
provides in-memory models to track shifts, sales, and inventory. It demonstrates
basic functionality for starting a shift, recording sales against nozzle meter
readings, and keeping inventory levels up to date.

## Running Tests

The project uses [pytest](https://docs.pytest.org/). To run the test suite:

```bash
pytest
```
